Проблема

Ресепшн каждый день теряет пациентов.

Очередь

Утром к одной стойке 10–15 человек. Часть уходит, не дождавшись.

Пропущенные звонки

Сотрудник занят — телефон без ответа. Это ушедший пациент.

Языковой барьер

Нужны три языка. В каждую смену их знают не все.

Ошибки и забывчивость

Не тот врач, устаревшая цена, незаписанный пациент.

Решение

Это не чат-бот.
Это цифровой сотрудник.

  • Видит — камера замечает пациента и сама начинает разговор.
  • Говорит — живым голосом: по-узбекски, по-русски, по-английски.
  • Делает — записывает к врачу, отмечает приход, печатает талон.
  • Знает меру — в сложной ситуации передаёт живому сотруднику.
Пациенту не нужны приложение, регистрация или поиск нужной кнопки.

Отдельная возможность

MyID — подтверждение пациента по государственной базе.

MyID — официальная система биометрической идентификации Узбекистана. У нас есть официальный договор с UZINFOCOM, поэтому киоск узнаёт пациента напрямую через государственную базу.

  • Киоск снимает лицо. Камера делает снимок пациента. Проверка liveness подтверждает, что перед камерой живой человек, а не фотография.
  • Сверка с государственной базой. Лицо сравнивается с фотографией из паспорта или ID-карты в базе MyID.
  • Данные заполняются сами. ФИО, дата рождения, ПИНФЛ и пол подставляются автоматически — пациент ничего не вводит.
Нет чужих и подставных пациентов

Интеграция

В какой системе работаете — к той и подключимся.

  • Один источник. Врачи, услуги и цены берутся из вашей системы — два справочника не ведутся.
  • Есть API — подключаемся напрямую. Нет API — работаем через базу или обмен файлами.
  • Закрытая сеть не помеха. К системе, доступной только в локальной сети, подключаемся через защищённый туннель.
  • Системы пока нет? Киоск работает на собственной базе, подключить можно в любой момент.
